# Integrated Final App

This directory tracks final integration checkpoints after milestone-level validation.

## Integration Rule
- A feature is merged into final integration only after its milestone checklist passes.

## Current Integrated Source
- `frontend/`
- `backend/`

## Suggested Workflow
1. Validate milestone checklist in `milestones/mX-*/README.md`.
2. Confirm run path on web and mobile.
3. Tag integration checkpoint (for example: `m1-pass`, `m2-pass`).
4. Move to next milestone.
