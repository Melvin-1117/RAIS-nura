# Milestone Workspace Layout

This folder organizes the project by PRD milestones.

- `speaker-count-extraction`: Recorded file upload + distinct speaker count
- `speaker-wise-speech-extraction`: Speaker-attributed transcript UI and timeline
- `speaker-recognition`: Known speaker profile matching
- `background-sound-segregation`: Speech/background separation
- `sound-categorization`: Background sound labeling and grouping
- `sound-distance-estimation`: Near/Mid/Far acoustic estimation
- `sound-intensity-analysis`: Loudness labeling and visualization
- `real-time-audio-intelligence`: Real-time streaming dashboard

## Current Source of Truth

The active implementation currently lives in:
- `frontend/`
- `backend/`

Use each milestone folder README as an acceptance checklist and implementation guide.
