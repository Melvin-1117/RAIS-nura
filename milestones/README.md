# Milestone Workspace Layout

This folder organizes the project by PRD milestones.

- `m1-speaker-count`: Recorded file upload + distinct speaker count
- `m2-speaker-wise-transcript`: Speaker-attributed transcript UI and timeline
- `m3-speaker-recognition`: Known speaker profile matching
- `m4-background-segregation`: Speech/background separation
- `m5-sound-categorization`: Background sound labeling and grouping
- `m6-distance-estimation`: Near/Mid/Far acoustic estimation
- `m7-intensity-analysis`: Loudness labeling and visualization
- `m8-live-audio-intelligence`: Real-time streaming dashboard

## Current Source of Truth

The active implementation currently lives in:
- `frontend/`
- `backend/`

Use each milestone folder README as an acceptance checklist and implementation guide.
